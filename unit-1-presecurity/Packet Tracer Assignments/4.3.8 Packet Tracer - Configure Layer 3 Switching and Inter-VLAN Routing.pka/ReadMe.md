Then we start the real work and start to configure the layer 3 switch, which he can route connects and understand IP addresses plus the L2 switch work. We have the port which connect to the internet and we neeed to configure it as routed port, because the interface needs to operate at Layer 3 and have an IP address. cuz in switch by default set as switch ports L2 ports understand mac addresses only and It can process some Layer 3 information, but it does not perform IP routing between networks. So we go to the MLS terminal and type en, the password, conf t, interface g0/2, no switch port, ip address 209.165.200.225 255.255.255.252 , no shutdown , and I will be reflecting 255.255.255.0 by /24 till the rest of this report, and by going back to root page by typing exit 2 times, we can run ping command. So we ping the 209.165.200.226 and by hitting enter we will have results as .!!!! So we know that the ping is working and step one done, and very important note that u make that port active by typing no shutdown as the last command, so the port will be active.

Now we need to add VLANs. Why we do that? Cuz the MLS will do routing the connect between the VLANs, so we have to make him meet eli tutustua those VLANs. We start by going into MLS CLIS and type , en, varia , conf t, vlan 10, name staff, exit. We do same for VLAN 20, 30, and names are Student for vlan 20 and Faculty for vlan 30. why choose this names koska this is what the task want

2nd step.

We need to configure switch virtual interface, what is it ? its like virtual interface for the vlans allow the devices in different vlans to communicate with each other. So its act like the default gateway for each vlan to allow us to have multi vlans on single hardware, and we do that by the following commands. We go to MLS, go to terminal CLI, start with en, varia, conf t, interface vlan 10, ip address 192.168.10.254/24, ipv6 address 2001:db8:acad:10::1/64, exit. And we do the same with vlan 20 - 30, but we use there respective IP addresses which we have them from the spread sheet with the assignment the addressing table, pluse we add the native vlan which is vlan 99 and give her the respective IP address v4 only cuz we didn't got ipv6 for it. And as long we are here, I just remember to give the interface G0/2 ipv6 address i just notice it in the sheet, so u can give the address also to it by running the following: en, varia , conf t, interface g0/2, ipv6 address 2001:db8:acad:a::1/64.

Step 3.

Now we have to configure the most important thing, which is the TRUNK, and what the trunk is? its the port which more than 1 vlan go through it. And if u look at the topology, we will see that G0/1 port the the perfect trunk port cuz he is going from the L3 switch, so we can route our connect by it. We start by the following.

Go to L3 switch, open CLI, type en, varia , conf t, interface g0/1, switchport mode trunk, switchport trunk encapsulation dot1q. What is that encapsulation thing and dot1q? Its the protocol used for the capsulation and tagging thing used by the trunk port, so the vlans can connect with each other, and also we have to configure the native vlan by typing switchport native vlan 99.

Now we need to configure the trunk port from the L2 switch POV. We go to the S1 and change the g0/1 to trunk and configure native vlan 99. We do the following: S1, en, varia, conf t, interface g0/1, switchport mode trunk, switchport trunk native vlan 99.

Now by what we have u think that the job is done, and if I wanna ping from vlan 10 pc to vlan 20 pc will work, but wrong!!. We forgot very important thing in layer 3 switch. If we go there and type show ip route, we will see noting. The routing is not active by default in L3 switches, so how we make it active? By going to the CLI of MLS and type, en, varia, conf t, ip routing.

Now we can check by running the command show ip route, and we will see that the switch now know that he have vlan 10 - 20 - 30 - 99 - and the g0/2 are connected to it, and the connection between them can by route by it. And to verify that, we can go to the pc in vlan 10 for example and open his command prompt and type ping the pc in vlan 20 which has the following IP 192.168.20.2, and we will have the ping working and the connect are active.

Now last thing we need to do that to enable the ipv6 routing in the layer 3 switch cuz if u remember we added ipv6 addresses to the vlans, and to enable this we type the following: go to CLI in MLS, type en, varia, conf t, ipv6 unicast-routing. And now u can test that by going to the pc in vlan 10 and ping the ipv6 address of the pc in vlan 20. U will see the ping is working, and by doing that our TEHTÄVÄ is done and the completion is 100%.
